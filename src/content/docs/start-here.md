This guide exists for people who are new to IBM Maximo and need plain-English explanations of what things mean and where they live in the product.

## Who this is for

- Students studying asset management or enterprise software
- Career switchers coming from other EAM or CMMS systems
- New Maximo users who want the "what does this actually mean" version

You do not need a Maximo login to use this guide. You do not need prior experience with EAM systems. If you can use a web browser and read English, you can use this guide.

## How to use it

There are three ways in:

**Learning paths** - If you are just getting started, pick a learning path from the sidebar. Each path is an ordered list of terms that build on each other. A good first path is "Your First Week in Maximo."

**Modules** - If you know which part of Maximo you are working in, go to the matching module. Each module page lists every term in that area, with filter buttons for difficulty.

**Search** - If you already know the term you are looking for, use the search box in the top bar.

## Riverbend Water Authority

Every example in this guide uses Riverbend Water Authority, a fictional municipal water utility. RWA treats water and distributes it across three sites. It has real-looking assets, locations, work orders, purchase orders, and everything else a Maximo installation would have.

Using one organization means you can follow the same pump, the same work order, and the same storeroom through every concept. When you read about an Asset in module 02 and a Reservation in module 05, the asset is the same pump.

See the [Riverbend Water](/maximo-field-guide/riverbend/) page for the full reference table.

## Review status badges

Each term has a review status badge:

- **Verified** - A practicing Maximo professional has reviewed this definition and confirmed it is accurate.
- **Draft** - The definition has been written but not yet reviewed.
- **In review** - A reviewer is actively checking this term.
- **Not started** - This term is in the plan but the definition has not been written yet.

This is a community draft. The verified badge is the one to trust. Draft terms are usable but may have small errors.
