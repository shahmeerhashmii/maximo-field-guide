Maximo is used by water utilities, railways, hospitals, oil refineries, and thousands of other organizations to manage their physical assets. It is powerful and it is complex. The official documentation is thorough, but it assumes you already know the vocabulary.

This guide tries to fill that gap. It gives you plain-English definitions you can read before you open the official docs, not instead of them.

## What this is

A community-built glossary tied to one fictional organization, Riverbend Water Authority. Each term has a definition, a location in the product, a real-feeling example from Riverbend Water, related terms, and a common misconception to watch out for.

The content comes from a structured spreadsheet and is being reviewed by Maximo practitioners. When a reviewer confirms a definition, the term gets a Verified badge.

## Who maintains it

This site was created by Shahmeer Hashmi and is open to contributions. The technical build was done with IBM Bob, an AI software engineering assistant. The content is human-written and is being reviewed by people who work with Maximo in the field.

## How to suggest a fix

If you spot an error in a definition, go to the [GitHub repository](https://github.com/shahmeerhashmii/maximo-field-guide) and open an issue using the "Content correction" template. Include the term name and what you think is wrong.

If you want to suggest a new term, use the "New term suggestion" template.

Pull requests that fix definitions or add new terms are welcome. See the CONTRIBUTING file in the repository for the full process.
